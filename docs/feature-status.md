# Source preview feature status

| Surface | Current status |
| --- | --- |
| Core-only vs optional local install | Two exact-version distributions and isolated launchers |
| Public generation | Fixed Ollama composition; live dispatch explicitly refuses missing server isolation |
| Shared candidate/check/cleanup pipeline | Reused through the trusted Kernel and frozen engine value types |
| Exact and scoped v2 authority | Closed local schemas; parent snapshots use the fixed public adapter |
| Attempt and review accounting | One root ledger, before-send debits, once-only dispatch, immutable outcomes |
| Local-only / external-only / combined work | Existing explicit user-owned `plzdo-private` composition; each engine must be configured and task-authorized |
| External generation/reviews | Optional `plzdo-integrations` package using the shared API; absent from strict public CLI |
| Private HN | Separate private adapter refuses unsupported v2 backend protocol |
| Managed browser checks | Explicit generated-file preview and coordinator observations; pending is not success |
| Original target apply/publication | No runtime authority |

This source preparation uses offline regression and a basic installation check. It does not make new provider/model calls or claim new live acceptance. Prior successful personal runs apply only to their recorded tools, profiles and execution paths. Changed code and installation are checked separately; other machines and provider versions remain unverified. See the root README for the supported source setup and explicit local-trust boundary.

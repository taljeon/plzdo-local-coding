# Selected historical evidence

These dated development results explain decisions; they are not this build's
test result or a cross-machine performance promise. Raw prompts, logs, local
paths, grants, machine policies and snapshots are intentionally not published.
Original private evidence is preserved separately, not deleted.

- 2026-09-11 standalone extraction (P2): 669 regression tests passed. A separate
  wheel exercised seven zero-provider CLI/contract/compute-handoff steps. Three
  synthetic Python/schema/text checks passed in the actual offline sandbox.
- That extraction included a small two-file packaging task generated in the first
  local attempt, approximately 74 seconds, with no Codex fallback and observed
  owned unload. This is one narrow development observation, not a benchmark score.
- 2026-09-12 personal scheduled-local successor: 801 tests and one explicitly
  approved manual synthetic artifact generation/check/cleanup passed. It used
  local Hui; runtime cloud provider calls were zero. A manual origin fixture is
  not proof of scheduler-origin execution.
- A separate private automation registration was subsequently activated under its
  own approval. Those settings/IDs/budgets are not part of this distribution and
  are not authority for another installation.

The public successor keeps source/test coverage for the earlier profiles and
failed-attempt/cleanup boundaries. Uninspected screenshots, archives and raw
historical materials are neither included nor claimed to have passed release
review. Current acceptance must be rerun on the exact candidate being delivered.
